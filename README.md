# StudyFocus 🎯

당신의 매일을 더 생산적으로 만들어주는 궁극의 목표 관리 및 공부 앱입니다. 직관적인 UI와 강력한 기능으로 당신의 꿈을 현실로 만들어 보세요!

## ✨ 주요 기능 (Key Features)

*   **📱 압도적인 UI/UX**: 하단 탭 메뉴와 부드러운 애니메이션, 모달 바텀 시트가 적용된 완벽한 사용자 경험. 스와이프로 할 일을 쉽게 삭제(Swipe to Dismiss)하거나 완료할 수 있습니다.
*   **🎯 목표와 할 일 분리**: 장기적인 목표(예: 토익 900점)를 세우고, 이를 이루기 위한 오늘의 할 일을 따로 관리하여 체계적인 계획 수립이 가능합니다.
*   **🍅 뽀모도로 타이머**: 25분 집중, 애니메이션이 적용된 타이머를 통해 공부의 효율을 극대화하세요.
*   **📊 주간 통계**: 지난 일주일간의 달성률을 한눈에 확인할 수 있는 아름다운 막대 그래프를 제공합니다.
*   **⏰ 사용자 맞춤형 알림**: 기존의 고정된 시간이 아닌, 사용자가 설정창에서 직접 원하는 시간을 지정하면 정확히 그 시간에 오늘의 달성률 알림이 울립니다.
*   **🇰🇷 완벽한 한국어 지원**: 모든 메뉴와 시스템 안내 문구가 자연스러운 한국어로 제공됩니다.

## 🛠️ 기술 스택 (Tech Stack)

*   **프론트엔드**: Android Native (Kotlin), Jetpack Compose
*   **아키텍처**: MVVM, Navigation Compose
*   **데이터베이스**: Room Database (다중 테이블 스키마)
*   **로컬 저장소**: Preferences DataStore (알림 시간 등 사용자 설정 영구 저장)
*   **백그라운드 처리**: WorkManager (매일 지정된 시간에 로컬 푸시 알림 발송)

## 🚀 설치 방법

1. `app/build/outputs/apk/debug/app-debug.apk` 경로의 최신 빌드 파일을 스마트폰으로 전송합니다.
2. 스마트폰에서 해당 APK 파일을 실행하여 설치를 진행합니다.
3. 앱을 최초 실행할 때 요구되는 **알림 권한**을 반드시 허용해 주세요.
